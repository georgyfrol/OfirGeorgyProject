Exercise 3:
In order to run the program with -load/-save the .exe file should be in the project main folder (where all .cpp and .h are).
The examples are in examples_steps_result.txt, in order to use them you need to put their content into adv-world.steps and adv-world.result respectively. (steps to steps, result to result).
The steps and result files formats are in files_format.txt.
